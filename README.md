# 🌸 HerCycle

### Personalized Menstrual Health & Wellness Tracker

HerCycle is a modern menstrual health and wellness web application that helps users track their menstrual cycles, monitor symptoms, understand cycle patterns, and explore wellness resources in one simple and user-friendly platform.

---

## 🌐 Live Website

🚀 **[Visit HerCycle](https://hercycle-tracker.vercel.app)**

**Production URL:**  
https://hercycle-tracker.vercel.app

---

## 📖 About HerCycle

HerCycle is designed to provide a personalized digital space for menstrual health tracking and wellness.

Users can:

- 🩸 Track their actual period dates
- 📅 View their cycle using an interactive calendar
- 📊 Analyze cycle history and trends
- 😊 Track mood and physical symptoms
- 💪 Record pain and energy levels
- 😴 Track sleep and other health metrics
- 🌸 View estimated cycle phases
- 🧘 Explore self-care and wellness videos
- 🛍️ Discover period-care and wellness products
- 👤 Manage their personal profile
- 🔐 Sign in securely using Firebase Authentication

HerCycle uses the user's recorded cycle history to provide personalized cycle information and analysis.

- 🌸 Predicted periods
- 🟣 Estimated ovulation
- 💚 Fertile window
- 🩵 Lower fertility
- 📆 Current cycle day
- 🌷 Current cycle phase

## 📊 Cycle Analysis

# 🔐 Authentication

HerCycle uses Firebase Authentication for secure user authentication.

### Email & Password

Users can create an account using their email address and password.

### Google Sign-In

Users can also sign in using their Google account.

For a first-time Google user, HerCycle provides a profile and health onboarding process.

Existing users with a completed profile can continue directly to the dashboard.

### Google Onboarding

![Google Onboarding](docs/screenshots/google-onboarding.png)

# ☁️ Firebase & Cloud Firestore

HerCycle uses Firebase as its cloud backend.

### Firebase Authentication

Used for:

- User registration
- Email/password login
- Google Sign-In
- Authentication state
- Protected routes

### Cloud Firestore

Used for storing application data such as:

- User profiles
- Period history
- Cycle information
- Symptoms
- Health metrics
- Wellness products
- Self-care resources

User-specific information is protected using Firestore security rules.
